# Aplikasi Konsol Pengolah Nilai

Jalankan program dari terminal dengan Node.js:

```bash
node nilai.js
```

Contoh alur keluaran:

```text
===== PENGOLAH NILAI =====
1. Input nilai siswa
2. Tampilkan rata-rata, nilai tertinggi, dan terendah
3. Tampilkan predikat lulus/tidak lulus per siswa
4. Keluar
Pilih menu (1-4): 1
Nama siswa: Budi
Nilai (0-100): 90
Nilai Budi berhasil disimpan.

Pilih menu (1-4): 2
Rata-rata: 90.00
Nilai tertinggi: 90
Nilai terendah: 90
Jumlah siswa lulus: 1
Jumlah siswa tidak lulus: 0

Pilih menu (1-4): 3
Budi: nilai 90, grade A, Lulus

Pilih menu (1-4): 4
Terima kasih.
```
